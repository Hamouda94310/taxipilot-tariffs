# Taxi Pilot — règles tarifaires distantes

Ce dépôt publie la configuration tarifaire utilisée par Taxi Pilot.

Fichiers :
- `manifest.json` : indique la configuration actuellement officielle.
- `tariffs-2026.json` : règles A/B/C correspondant à la logique de Taxi Pilot Build 62.

Important :
- ne jamais ajouter de mot de passe, clé API ou clé privée dans ce dépôt ;
- toute modification doit être vérifiée avant publication ;
- l’application devra conserver une configuration locale de secours.
